Chat History Hub — 대화 목록
전체 설치 패키지 1.4.1 / 2026-10-30
Mac·Windows의 Chrome 공용입니다. 이전 버전 없이 이 폴더만으로 처음 설치할 수 있습니다.

[처음 설치 — 각 PC에서 한 번]
1. ZIP의 압축을 풉니다.
   Mac: ZIP을 더블클릭합니다.
   Windows: ZIP을 오른쪽 클릭하고 '모두 압축 풀기'를 선택합니다.
2. 이 chat-history-browser-extension 폴더 전체를 '문서' 등 보관할 위치로 옮깁니다.
   폴더에는 manifest.json, background.js, quick-sync.js, icons 등이 있습니다.
   js 파일을 더블클릭해서 실행하는 프로그램이 아닙니다.
3. 사용할 Chrome 프로필에서 주소창에 chrome://extensions 를 입력합니다.
4. 오른쪽 위 '개발자 모드'를 켭니다.
5. '압축해제된 확장 프로그램을 로드합니다'를 누릅니다.
6. manifest.json 파일이 들어 있는 이 폴더를 선택합니다.
   ZIP 파일이나 manifest.json 파일 자체를 선택하지 않습니다.
7. 'Chat History Hub — 대화 목록' 카드의 버전 1.4.1과 켜짐 상태를 확인합니다.

[사용]
1. 같은 Chrome에서 ChatGPT에 로그인합니다.
2. https://baelab-create.github.io/chat-history-hub/ 에서 기존 Google 계정으로 로그인합니다.
3. 이미 열려 있던 대화 목록 페이지는 새로고침합니다. Mac: Cmd+R / Windows: Ctrl+R
4. 대화 목록의 '최신화'를 누릅니다.
   프로그램이 확인용 ChatGPT 탭을 열고 최근 목록을 읽어 저장합니다.
   로그인이 필요하거나 페이지를 읽지 못하면 안내가 표시됩니다.
   완료 시 '최근 목록 N개 반영 · 날짜 N개 확인 · 저장 완료'를 확인합니다.
5. Chrome 오른쪽 위 퍼즐 아이콘에서 이 프로그램을 고정하면 찾기 쉽습니다.
   아이콘을 누르면 '내 대화 목록 열기' 버튼이 나옵니다.

[여러 PC에서 사용]
- 같은 ZIP을 각 PC로 가져가 위의 처음 설치 절차를 진행합니다.
- 사용하는 Chrome 프로필마다 별도로 등록합니다.
- 같은 대화를 모으려면 각 PC의 ChatGPT에도 같은 계정·워크스페이스를 사용합니다.
- 대화 목록 사이트에는 기존에 사용하던 같은 Google 계정으로 로그인합니다.
- 공유 저장이 완료된 목록은 다른 PC에서도 같은 계정으로 불러올 수 있습니다.
- 로컬 작업 원문은 이 확장 프로그램으로 다른 PC에 복사되지 않습니다.
- 등록한 폴더는 설치 후에도 삭제하거나 옮기지 않고 보관합니다.

[이미 구버전이 설치된 PC만]
기존 폴더를 안다면 새 패키지의 파일 전체를 덮어쓰고 chrome://extensions의
해당 카드에서 새로고침(원형 화살표)을 누른 뒤 Hub 페이지도 새로고침합니다.
기존 폴더를 모르시면 기존 'Chat History Hub — 대화 목록' 항목만 삭제하고
새 폴더를 위 절차로 등록합니다. Hub에 저장된 대화 목록은 유지됩니다.
처음 설치하는 PC에는 이 업데이트 절차가 필요 없습니다.

[범위와 확인 상태]
- 제목·대화 링크·확인 가능한 날짜만 수집하며 본문·쿠키·로그인 정보는 수집하지 않습니다.
- 최신화는 불러온 최근 목록을 추가하는 기능이며 전체 과거 대화의 완전한 동기화는 아닙니다.
- 오래된 목록은 Hub '설정 및 가져오기 → 과거 대화·다른 탭에서 가져오기'를 사용합니다.
- 날짜가 없는 대화는 미확인으로 남습니다.
- 패키지 구성과 수집·취소·저장 흐름을 모의 환경에서 검증했습니다.
  실제 로그인된 각 PC에서의 자동 수집 성공까지 검증한 것은 아닙니다.
