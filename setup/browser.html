Chat History Hub
처음 설치하는 전체 패키지

이 PC에 처음 설치하신다면 아래 순서대로 진행하세요. 기존 버전 없이 이 ZIP 하나로 설치할 수 있습니다.

전체 패키지 1.4.1 · 2026년 10월 30일
전체 설치 ZIP 다운로드 · 1.4.1

Mac·Windows Chrome 공용 · 이전 버전 불필요 · 설치 설명서 포함
여러 PC에서 같은 파일을 사용하실 수 있습니다.

처음 설치 · 각 PC에서 한 번

  1. 다운로드한 ZIP의 압축을 풉니다.
    MacZIP 파일을 더블클릭합니다.
    WindowsZIP을 오른쪽 클릭 → ‘모두 압축 풀기’를 선택합니다.
  2. chat-history-browser-extension 폴더 전체를 ‘문서’ 등 계속 보관할 위치로 옮깁니다. 폴더를 열었을 때 manifest.json, background.js, quick-sync.js, icons 등이 보이면 맞습니다. 파일을 하나씩 더블클릭해서 실행하지 않습니다.
  3. 사용할 Chrome을 열고 주소창에 chrome://extensions를 입력합니다. 오른쪽 위 ‘개발자 모드’를 켭니다.
  4. 왼쪽 위 ‘압축해제된 확장 프로그램을 로드합니다’를 누르고, 2번의 manifest.json이 들어 있는 폴더를 선택합니다. ZIP이나 개별 파일 대신 폴더 전체를 선택하세요.

‘Chat History Hub — 대화 목록’ 카드에 1.4.1이 표시되고 스위치가 켜져 있으면 Chrome에 등록된 상태입니다.

설치 후에도 등록한 폴더는 그대로 보관하세요. 폴더를 삭제하거나 옮기면 Chrome이 프로그램을 읽을 수 없습니다.

설치 후 사용하는 방법

  1. 같은 Chrome에서 ChatGPT에 로그인합니다.
  2. 내 대화 목록에서 기존 Google 계정으로 로그인합니다. 이미 열려 있던 페이지라면 Mac은 ⌘ + R, Windows는 Ctrl + R로 새로고침합니다.
  3. ‘최신화’를 누릅니다. 프로그램이 확인용 ChatGPT 탭을 열고 최근 목록을 읽어 저장합니다.

‘최근 목록 N개 반영 · 날짜 N개 확인 · 저장 완료’가 표시되면 해당 수집과 저장이 완료된 것입니다.

로그인이나 추가 확인이 필요하면 화면에 안내가 나옵니다. 설치만으로 대화를 수집하지는 않습니다.

아이콘으로 쉽게 열기

Chrome 오른쪽 위 퍼즐 아이콘을 누르고 ‘Chat History Hub — 대화 목록’ 옆의 고정 아이콘을 누르세요. 청록색 말풍선 아이콘을 누르면 ‘내 대화 목록 열기’ 버튼이 나옵니다.

다른 PC에도 설치하려면

같은 ZIP을 각 PC에 받아 위의 ‘처음 설치’ 절차를 진행하세요. 사용하는 Chrome 프로필마다 한 번씩 등록합니다.

  • 같은 대화를 모으려면 ChatGPT에도 같은 계정·워크스페이스를 사용합니다.
  • 대화 목록 사이트에는 기존에 사용하던 같은 Google 계정으로 로그인합니다.
  • 공유 저장을 마친 목록은 다른 PC에서 같은 계정으로 불러올 수 있습니다. 로컬 작업의 원문 파일은 다른 PC에 복사되지 않습니다.
이미 구버전이 설치된 PC만: 업데이트 방법

처음 설치하는 PC에는 이 과정이 필요 없습니다.

기존 폴더를 아시면 새 패키지의 파일 전체를 덮어쓴 뒤 chrome://extensions의 해당 카드에서 새로고침 아이콘(↻)을 누릅니다. 내 대화 목록 페이지도 새로고침하세요.

기존 폴더를 모르시면 기존 ‘Chat History Hub — 대화 목록’ 항목만 삭제한 뒤, 새 폴더를 위의 처음 설치 방법으로 등록하세요. Hub에 저장된 대화 목록은 유지됩니다.

가져오는 범위와 확인 상태

현재 로그인된 ChatGPT 계정·워크스페이스에서 불러온 최근 대화의 제목·링크·확인 가능한 날짜를 가져옵니다. 본문·쿠키·로그인 정보는 수집하지 않습니다. 날짜가 없는 대화는 미확인으로 남습니다.

전체 과거 대화를 모두 읽는 기능은 아닙니다. 오래된 대화나 특정 탭의 목록은 ‘설정 및 가져오기 → 과거 대화·다른 탭에서 가져오기’를 이용하세요.

패키지 구성과 수집·취소·저장 흐름은 모의 환경에서 검증했습니다. 실제 로그인된 각 PC에서의 자동 수집 성공까지 확인한 것은 아닙니다.
