ChatGPT 대화 목록 수집기

Chrome에서 한 번 설치하면 Hub의 ‘최신화’ 버튼으로 이전 대화까지 누적해서 가져올 수 있습니다.

  1. 확장 프로그램 다운로드 후 압축을 풉니다.
  2. Chrome 주소창에 chrome://extensions를 입력합니다.
  3. ‘개발자 모드’를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’를 누릅니다.
  4. 압축을 푼 폴더 안의 manifest.json이 있는 폴더를 선택합니다.
  5. Hub 페이지를 새로고침합니다.

가져오기

같은 Chrome에서 ChatGPT 홈을 열고 최근 목록을 펼칩니다. Hub의 ‘최신화’를 누르면 미리보기 창이 열립니다. 계정과 탭을 확인하고 ‘과거 대화까지 읽기’ → ‘이 목록을 Hub에 반영’을 누르세요.

사이드바를 아래로 이동하며 이전 대화의 제목과 링크를 모읍니다. 읽는 동안 선택한 탭을 그대로 두세요. 추가 로딩이 멈추거나 오류·중단이 발생하면 수집 개수와 이유를 보여줍니다. 한 번에 최대 50,000개, 20분까지 읽고 기존 목록에 누적합니다. 보관함 등 계정 전체 내역의 완전한 수집을 보장하지 않으며 본문과 로그인 쿠키는 읽지 않습니다. 정확한 수정일을 읽을 수 없으므로 수집 시각으로 날짜를 만들지 않습니다. 페이지 구조가 달라지면 수집을 중단하고 오류를 표시합니다.

확장 프로그램에는 chatgpt.com과 이 사이트 호스트 접근 권한이 필요합니다. 실제 코드는 ChatGPT 사이드바와 /chat-history-hub/ 경로에서만 동작합니다. 목록을 보내기 전에 확장 프로그램 미리보기에서 확인합니다.
