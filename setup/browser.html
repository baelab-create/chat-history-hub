앞으로는 ‘최신화’ 한 번으로.

확장 프로그램을 처음 한 번 연결하면, 대화 목록 페이지에서 최신화를 눌러 최근 대화를 가져올 수 있습니다.

버전 1.4.0 · 2026년 10월 27일 · Chrome용

확장 프로그램 1.4.0 다운로드

이미 설치하셨다면

  1. 다운로드한 ZIP 파일의 압축을 풉니다.
  2. 새 파일을 기존에 확장 프로그램으로 등록한 폴더에 덮어씁니다. 새 폴더만 만드는 것으로는 업데이트되지 않습니다.
  3. Chrome 주소창에 chrome://extensions를 입력합니다.
  4. ‘Chat History Hub — 대화 목록’ 카드의 새로고침 아이콘(↻)을 누릅니다. 버전이 1.4.0인지 확인하세요.
  5. 내 대화 목록으로 돌아가 페이지를 새로고침합니다.

기존 설치 폴더를 모르시면 확장 프로그램 카드에서 기존 항목을 제거한 뒤 아래 방법으로 새로 등록하실 수 있습니다. Hub에 저장한 대화 목록은 유지됩니다.

처음 설치하시는 경우
  1. 다운로드한 ZIP 파일의 압축을 풉니다. 폴더는 설치 후에도 보관하세요.
  2. Chrome 주소창에 chrome://extensions를 입력합니다.
  3. 오른쪽 위 ‘개발자 모드’를 켭니다.
  4. ‘압축해제된 확장 프로그램을 로드합니다’를 누르고 manifest.json이 들어 있는 폴더를 선택합니다.
  5. 내 대화 목록으로 돌아가 페이지를 새로고침합니다.

연결 후 사용하는 방법

내 대화 목록에서 최신화를 누르세요. 프로그램이 ChatGPT 확인용 탭을 열어 최근 목록을 읽고 저장합니다. 탭 선택이나 ‘목록 반영’ 버튼을 다시 누를 필요가 없습니다.

같은 Chrome에서 ChatGPT에 로그인되어 있어야 합니다. 로그인이나 추가 확인이 필요한 경우에는 안내에 따라 완료한 뒤 최신화를 다시 누르세요.

무엇을 가져오나요?

현재 로그인된 계정·워크스페이스에서 불러온 최근 대화의 제목·링크·확인 가능한 날짜를 가져옵니다. 대화 본문·쿠키·로그인 정보는 수집하지 않습니다. 기존 대화와 날짜는 유지하고 새 자료를 합칩니다.

최신화는 전체 과거 대화를 모두 읽는 기능은 아닙니다. 오래된 대화나 특정 탭의 목록은 ‘설정 및 가져오기 → 과거 대화·다른 탭에서 가져오기’를 이용하세요. 날짜가 없는 항목은 미확인으로 남습니다.

확인용 탭은 작업이 끝나면 닫힙니다. 직접 열어보신 탭이나 로그인에 필요한 탭은 닫지 않습니다. 페이지 방문이나 일정에 따른 자동 수집은 하지 않습니다.

수집·취소·저장 흐름은 모의 환경에서 검증했습니다. 실제 로그인된 사용자 Chrome에서의 새 자동 흐름은 아직 확인하지 못했습니다.

설치 없이 북마크로 가져오기도 가능합니다. 이 방식은 ChatGPT 화면에서 북마크를 직접 눌러야 합니다.
