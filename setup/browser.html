ChatGPT 대화 목록 수집기

설치가 번거로우신가요? 북마크 버튼 방식 보기

버전 1.2.0 · 2026년 10월 24일

웹사이트를 업데이트해도 PC에 압축해제하여 설치한 확장 프로그램은 자동으로 바뀌지 않습니다. 이미 사용 중이셨다면 아래 업데이트 절차를 한 번 진행해 주세요.

수집기 1.2.0 다운로드

기존 수집기 업데이트

  1. ZIP 파일을 내려받아 압축을 풉니다.
  2. 기존에 확장 프로그램을 설치했던 폴더의 파일을 새 파일로 교체합니다. manifest.json이 있는 폴더가 기준입니다.
  3. Chrome 주소창에 chrome://extensions를 입력하고, ‘Chat History Hub — 대화 목록’의 새로고침 버튼을 누릅니다. 버전이 1.2.0인지 확인하세요.
  4. 이전 설치 폴더를 모르면 기존 수집기를 삭제한 뒤, 아래 처음 설치 절차로 새 폴더를 선택하셔도 됩니다. Hub의 기존 대화 목록은 삭제되지 않습니다.
  5. Hub 페이지를 새로고침하고 ‘수집기 연결 확인’을 누릅니다.

처음 설치

  1. 위 ZIP을 내려받아 압축을 풉니다.
  2. chrome://extensions에서 ‘개발자 모드’를 켭니다.
  3. ‘압축해제된 확장 프로그램을 로드합니다’를 누르고 manifest.json이 있는 폴더를 선택합니다.
  4. Hub 페이지를 새로고침한 뒤 ‘수집기 연결 확인’을 누릅니다.

최신 대화 가져오기

  1. 같은 Chrome에서 ChatGPT에 로그인하고 대화 사이드바를 펼칩니다.
  2. Hub에서 ‘최신화’를 누릅니다.
  3. 열린 미리보기에서 자신의 ChatGPT 탭을 선택하고 ‘최근 목록 빠르게 읽기’를 누릅니다.
  4. 목록을 확인한 뒤 ‘이 목록을 Hub에 반영’을 누릅니다.
  5. Hub에서 가져온 개수와 공유 저장 결과를 확인합니다. 검색·날짜 필터가 남아 있으면 ‘초기화’를 눌러 전체 목록을 보세요.

과거 내역도 추가하려면 ‘과거 대화까지 읽기’를 선택하세요. 진행 중 ‘여기까지 읽기’로 중단하고 현재 결과만 반영할 수 있습니다. 미리보기를 닫으면 요청이 취소됩니다.

저장 목록과 새 대화의 차이

‘저장 목록 다시 불러오기’는 다른 PC에서 이미 공유한 기록을 읽습니다. ‘최신화’는 현재 Chrome의 ChatGPT 화면에서 새 제목과 링크를 읽습니다. 자동 수집이나 예약 작업은 실행하지 않습니다.

본문·쿠키·로그인 정보는 수집하지 않습니다. 제목과 링크에 필요한 식별자만 암호화해 보관합니다. 한 번에 최대 50,000개, 20분까지 읽으며, 보관함이나 표시되지 않은 프로젝트 등 계정 전체 내역을 보장하지 않습니다. 정확한 수정일을 읽을 수 없는 항목에는 임의 날짜를 붙이지 않습니다.
