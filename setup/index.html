버튼을 누를 때만 최신화

연결 도구는 이 PC의 제목 목록을 한 번 읽고 종료합니다. 주기적인 수집이나 화면 조작은 하지 않습니다.

  1. 수동 연결 도구 다운로드 후 압축을 풀어 주세요.
  2. Windows: Install-Manual-Windows.cmd를 실행합니다.
    Mac: 터미널에서 압축을 푼 폴더로 이동한 뒤 sh Install-Manual-Mac.command를 실행합니다. Mac 설치 과정은 이 Windows PC에서 실기기 검증하지 못했습니다.
  3. 이 PC의 ChatGPT/Codex 앱을 열고 로그인해 주세요.
  4. Hub에 Google 로그인한 뒤 이 PC에서 최신화를 누릅니다. 브라우저가 연결 도구 열기와 로컬 연결을 물으면 허용합니다.

Node.js 22 이상과 Python 3이 필요합니다. Windows에서는 설치된 Codex의 실행 환경을 먼저 찾습니다. GitHub 로그인은 필요하지 않습니다. 실행이 실패하면 브라우저의 보안 설정을 끄지 말고 오류 안내를 확인해 주세요.

수집되는 범위

앱에서 조회 가능한 최근 목록 최대 50개에 포함된 ChatGPT 대화와 고정 대화, 이 PC에 저장된 이름 있는 로컬 작업입니다. 앱 연결은 버전에 따라 지원되지 않을 수 있습니다. 실패하면 이전 목록을 유지합니다. 대화 본문은 저장하거나 전송하지 않습니다.

삭제된 대화를 확실히 구별할 수 없어 목록에서 자동으로 제거하지 않습니다. 다른 PC의 로컬 작업 제목도 보이지만, 해당 작업을 열려면 그 작업이 있는 PC에서 최신화해야 합니다.

공유 목록 불러오기는 이미 다른 PC에서 저장한 목록만 읽습니다. 다른 PC를 작동시키거나 수집하지 않습니다. PC마다 연결 도구 설치는 한 번 필요합니다.

기존 자동 수집 작업은 이 설치 과정에서 중지합니다. 새 자동 실행 작업은 등록하지 않습니다.
