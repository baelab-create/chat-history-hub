다른 PC 자동 연결

현재 데스크탑의 자동 연결은 설치되어 있습니다. 다른 PC의 로컬 작업도 모으려면 그 PC에서 한 번 설치해 주세요.

  1. ChatGPT 데스크톱 앱에 같은 계정으로 로그인하고 실행해 둡니다.
  2. 자동 연결 설치 파일을 내려받아 압축을 풉니다.
  3. Windows는 Install-Windows.cmd를 실행합니다. Mac은 터미널에서 sh Install-Mac.command를 실행합니다.
  4. 설치 후 목록 페이지에 해당 PC의 자동 연결 중 표시와 새 확인 시각이 나타나는지 확인합니다.
설치 조건

Python 3와 GitHub CLI가 필요합니다. GitHub CLI는 저장소 소유 계정으로 로그인되어 있어야 합니다. 아직 로그인하지 않았다면 터미널에서 gh auth login으로 진행합니다. Google 로그인은 목록을 열 때 사용합니다.

Windows 자동 실행은 검증되었습니다. Mac 설치 프로그램은 준비되어 있으나 이 PC에서 Mac의 실행 결과를 확인할 수 없습니다.

설치된 수집기는 AI를 호출하지 않습니다. 앱이 켜져 있으면 1분마다 제목을 확인하고, 바뀐 목록을 암호화해 전송합니다. GitHub 전달 때문에 화면 반영에 몇 분 더 걸릴 수 있습니다. PC를 껐다 켜거나 잠자기에서 돌아오면 다시 연결을 시도합니다.

본문·비밀번호·로그인 토큰은 수집하지 않습니다. 최근 목록에 없다는 이유로 이전 대화를 삭제하지 않습니다. 모든 과거 대화와 삭제 내역의 완전한 복제는 지원하지 않습니다.
