대화 목록 가져오기

북마크바가 안 보이면 Windows: Ctrl + Shift + B
Mac: ⌘ + Shift + B

앞으로 가져올 때

  1. ChatGPT에서 대화 사이드바를 펼칩니다. 최신 대화를 가져오려면 목록의 맨 위로 이동합니다.
  2. 북마크바의 ‘대화 목록 가져오기’를 누릅니다.
  3. 이동한 대화 목록 사이트에서 제목을 확인하고 ‘이 목록 반영’을 누릅니다. 로그아웃 상태라면 먼저 로그인합니다.

같은 탭에서 대화 목록 사이트로 이동합니다. 작성 중인 내용은 먼저 마무리해 주세요. 화면에 불러온 제목·링크 식별자만 최대 200개까지 가져오며, 전체 과거 대화를 자동 수집하지 않습니다. 제목은 이동 전에 암호화되며 본문·쿠키·로그인 정보는 읽지 않습니다.

ChatGPT 또는 브라우저의 보안 설정에 따라 북마크 실행이 차단될 수 있습니다. 버튼이 반응하지 않으면 기존 확장 프로그램 방식을 이용해 주세요. 실제 로그인된 ChatGPT에서의 실행은 아직 확인하지 못했습니다.
